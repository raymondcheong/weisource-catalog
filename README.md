# Product images folder

Put your product photos here.

## Naming tip

Use the same name as the SKU or product `id`, for example:

- `cl-ank-001.jpg` → used in `products.js` as `"image": "images/products/cl-ank-001.jpg"`
- `mb-mix-100.jpg`
- `sb-pr-201.jpg`

## Supported formats

- `.jpg` / `.jpeg` (recommended — smaller file size)
- `.png`
- `.webp`

## Recommended size

- **Width:** 800–1200 px
- **Aspect ratio:** portrait 3:4 (like a phone photo of the item)
- **File size:** under 300 KB per image (compress at [tinypng.com](https://tinypng.com) if needed)

## Do not

- Use spaces in file names (use `-` instead: `school-bag-blue.jpg`)
- Upload huge originals (5 MB+) — they slow the site on mobile data
