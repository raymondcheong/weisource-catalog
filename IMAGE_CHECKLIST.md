# Your 3 products — image file names

Put your photos in **this folder** (`images/products/`), using these exact names:

| Product | Save image as |
|---------|----------------|
| Cotton T-Shirt (~300g) | `cl-tshirt-300g.jpg` |
| Quality Tote Bags | `mb-tote-quality.jpg` |
| Mixed Heels | `sh-mixed-heels.jpg` |

After copying files, refresh the website in your browser.

If you use different file names, update the `image` line in `js/products.js` to match.
